# 初級中国語会話 — 教材サイト

スマートフォン・タブレット・パソコンのどれからでも使える、静的な（サーバー不要の）
中国語教材サイトです。フォルダごとコピーすれば、そのまま動きます。

---

  kaiwa.js              全ページ共通の動き（音声・表示切替・答え合わせ）

  homework/

## 2. よくある編集

### 答えを直したい

`1k/homework/kaiwa/1k-a.js` を開きます。形式は今までと同じです。

```js
// 大問題１
var answerFirstArr = ["1#ba4","2#jie3", …];
```

`"小問番号#正解"` の形です。空らんが複数ある問題は `@` で区切ります。

```js
"1#姓@叫@私の苗字は山田で、山田愛子と言います。"
```

> 答え合わせは、全角と半角、大文字と小文字、空白、句読点（，。？！）の
> あるなしを区別しません。
>
> **ピンイン（大問1）**：答えのファイルは `la3o` のように「記号がつく母音の直後に数字」
> の書き方ですが、学生が `lao3`（数字を最後）や `lǎo`（声調記号）と打っても正解になります。
> 答えのファイルはこれまでどおりの書き方のままで大丈夫です。
>
> **簡体字**：日本語入力で `愛` `習` などと打った場合は、×ではなく
> 「△ おしい！ 簡体字で書きましょう　愛→爱」と表示します（記録上は不正解）。

### 本文に会話を 1 行足したい

`1k-h-1.html` の `<ol class="lines">` の中に、同じ形でもう 1 つ `<li>` を足します。

```html
<li class="line" data-audio="1k-h-5" tabindex="0" role="button" aria-label="この文を再生">
  <span class="spk">A</span>
  <p class="l-ch" lang="zh-Hans">谢谢。</p>
  <p class="l-py" data-lang="py">Xièxie.</p>
  <p class="l-jp" data-lang="jp" lang="ja">ありがとう。</p>
</li>
```

`data-audio="1k-h-5"` と書くと `sound/1k-h-5.mp3` を鳴らします。
**行を増やしても JavaScript を直す必要はありません。**
（以前は行数が JavaScript に直接書かれていて、増やすたびに書き足す必要がありました）

### 本文のピンインと「読んでいる所」の表示

本文では、ピンインを 1 字ずつ漢字の真上に表示し、音声に合わせて
**いま読んでいる字に黄色のマーカー**、読み終わった字を青にします。

- ピンインの割りふりは、変換ツール（`tools/convert.py`）が元のページの
  中国語とピンインから自動で行います（第1〜7課の本文 88 行すべて対応済み）。
  対応がとれない行があると変換のときに表示され、その行だけ今までどおり
  ピンインを下に 1 行で出します。中国語とピンインの字数が合っているか確認してください。
- どの字を何秒目に読むかは、変換ツールが **録音そのものを解析** して求め、
  各行の `data-t`（各音節の読みはじめの秒）と `data-end` に書き込みます。
  解析には `ffmpeg` と Python の `numpy` が必要です。ない環境で変換した場合は、
  音声の長さから目安で色をつけます。
- 録音を差しかえたときは、変換ツールをもう一度実行してください。
- 文法ポイントの例文（152 文）も、ピンインを漢字の上に表示しています。

### 単語を足したい

`1k-t1-1.html` の `<ul class="words">` に `<li class="word" …>` を足します。形は上と同じです。

### 色や文字の大きさを変えたい

`assets/kaiwa.css` のいちばん上、`:root { … }` の中だけ直せば全ページに反映されます。

```css
--accent: #0b63c5;   /* ボタンやリンクの色 */
--py:     #0f7a5a;   /* ピンインの色 */
```

## 3. 第8課〜第14課を追加するとき

1. 旧形式のフォルダ（`8k/` など）を、変換前の素材フォルダに置きます。
2. 次を実行します。

```bash
python3 tools/convert.py <変換前のフォルダ> <出力先のフォルダ>
```

3. トップページの「準備中」が自動でリンクに変わります。

変換ツールは何度実行しても同じ結果になります。

---

## 4. 公開のしかた

ファイルを置くだけで動きます（PHP などは不要です）。

- **GitHub Pages**: リポジトリの Settings → Pages で、このフォルダを公開に設定します。
- **大学のサーバー**: フォルダごとアップロードします。
- **オフライン**: USB などにコピーし、`index.html` をブラウザで開きます。

## 5. 今回直した主な点

### 不具合

| 直したこと | 以前の状態 |
|---|---|
| スマートフォン対応 | 画面指定がなく、スマホでは全体が小さく表示されていました |
| 表示切替（中国語/日本語/ピンイン） | 行数が合わず、切り替えのたびにエラーが出ていました |
| 練習問題の選択肢 | 選ぶたびに、存在しない関数を呼んでエラーが出ていました |
| 第4課 問題3-2 ほか | 答え合わせの処理にまちがいがあり、押しても何も起きませんでした |
| 声調の問題（大問1） | 70問中40問で、`lao3` や `lǎo` と正しく答えても×になっていました |
| 答え合わせ | 全角・空白・句読点が 1 つ違うだけで不正解になっていました |
| 音声 | クリックのたびに再生処理が積み重なっていました |
| 中国語の字形 | 端末によって日本語の漢字で表示されていました（`lang` 指定で解決） |
| ボタンの大きさ | 高さ 30px で、指では押しにくい大きさでした |
| リンク切れ | 第7課の「前へ」が存在しないファイルを指していました |
| 画像の重複 | 同じイラストが課ごとに置かれていました（77 → 11 ファイル） |

### 学生が使いやすくなったところ

- **○×の記録**：問題ページの上に ①②③… が緑（○）・赤（×）で並び、タップでその問題へ。
  問題一覧には「8/10」、最後のページには課全体の集計と「やり直す」リンク。
  記録はその端末のブラウザの中だけに残り、サーバーには送られません。
  （その問題を開いて最初の答え合わせだけを記録するので、答えを見て打ち直しても点は増えません）
- **次に何をするか迷わない**：本文 → 単語 → 文法 → 練習問題 と、
  各まとまりの最後に「次は 〇〇 →」ボタン。
- **聞き取り**：練習問題に「ゆっくり」（0.75倍）ボタン。本文・単語は速さを 3 段階で切り替え。
- **ピンインと文字を一対一に**：ピンインを 1 字ずつ漢字の真上に表示。
  再生中は、いま読んでいる字に黄色のマーカー、読み終わった字は青（録音を解析して時刻を合わせています）。
- **表示の切り替え**：「ピンイン」「日本語訳」をそれぞれ ON/OFF。消しておけば暗記の練習に。
  設定は次のページにも引きつがれます。
- **入力のしやすさ**：スマホの自動修正・自動大文字をオフ。日本語入力の変換確定の Enter で
  答えが出てしまわないようにしました。正解したら Enter でそのまま次の問題へ。
- **画面の広さ**：スマホで上に固定される部分を画面の 22% → 14% に。
- そのほか：キーボードだけでも操作可能、ダークモード、印刷用レイアウト。
