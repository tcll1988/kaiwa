  1. A

    这 是 铅 笔 还 是 圆 珠 笔？

    Zhè shì qiānbǐ háishi yuánzhūbǐ？

    これは鉛筆ですか。それともボールペンですか。

  2. B

    这 是 圆 珠 笔。

    Zhè shì yuánzhūbǐ.

    これはボールペンです。

  3. A

    那 也 是 圆 珠 笔 吗？

    Nà yě shì yuánzhūbǐ ma？

    あれもボールペンですか。

  4. B

    是, 那 也 是 圆 珠 笔。

    Shì, nà yě shì yuánzhūbǐ.

    はい、あれもボールペンです。

  5. A

    这 些 都 是 你 的 圆 珠 笔 吗？

    Zhèxiē dōu shì nǐ de yuánzhūbǐ ma？

    これらは全部あなたのボールペンですか。

  6. B

    不 是, 这 是 我 的, 那 是 高 桥 的。

    Búshì,zhè shì wǒ de, nà shì Gāoqiáo de.

    いいえ、これは私の（ボールペン）です。あれは高橋さんの（ボールペン）です。

  7. A

    这 是 你 的 词 典 吧？

    Zhè shì nǐ de cídiǎn ba？

    これはあなたの辞書でしょう。

  8. B

    是, 这 是 我 的 词 典。

    Shì, zhè shì wǒ de cídiǎn.

    はい、これは私の辞書です。

  9. A

    那 些 也 都 是 你 的 词 典 吗？

    Nàxiē yě dōu shì nǐ de cídiǎn ma？

    あれらもあなたの辞書ですか。

  10. B

    不 是, 那 些 不 是。

    Búshì, nàxiē búshì.

    いいえ、あれらは違います。
